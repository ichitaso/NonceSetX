# Artwork

- `AppIcon-1024.png`: current app icon. Cloud + sparkles on a blue gradient (the cloud follows NonceSet143's icon, a nod to OTA updates). Refined with ChatGPT from a cloudB6 draft (`make_cloud.py`), then resized to 1024.
- `make_repo_art.py`: makes the repo icon and the depiction banner (`python3 make_repo_art.py ~/Documents/apt`).
- `make_launch_icon.py`: makes `Resources/LaunchIcon@2x/@3x.png` (launch screen icon, rounded) from `AppIcon-1024.png`.
- `make_cloud.py`: script that drew the cloudB6 base (`python3 make_cloud.py out.png sparkle`).
- `Screenshots/`: screenshots for the README and the depiction (iPhone 11 Pro, iOS 26.0.1).

App icon PNGs in `Resources/` are exported from `AppIcon-1024.png`.
